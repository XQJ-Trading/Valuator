# root.1

위성 이미지 산업의 전방 수요(정부, 상업용)와 밸류체인을 분석하고, 차년도 실적에 영향을 미칠 긍정적 요인과 리스크를 전망합니다.

## Children

- **root.1.0** (`web_search_tool`): Planet Labs의 정부 및 상업용 전방 수요 동향과 주요 고객군 수주 잔고 분석
- **root.1.1** (`domain_tool`): 위성 데이터 수집, 처리, 서비스 제공에 이르는 밸류체인 내 Planet Labs의 위치와 경쟁력 분석
- **root.1.2** (`web_search_tool`): 차년도 실적 성장을 견인할 긍정적 촉매제(신규 위성 발사, 계약 갱신 등)와 하방 리스크(거시 경제, 경쟁 심화) 분석
